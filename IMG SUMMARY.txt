## 1. Overall Design Language

The reference interface follows a clean, light, minimal, professional dashboard and web-application style.

### Color palette
- Use a predominantly white background.
- Use a very light gray for secondary backgrounds, information panels, and subtle surface separation.
- Use a professional medium-to-deep blue as the primary accent color for buttons, links, active navigation, highlighted prices, and important actions.
- Use dark navy or near-black for headings and primary text.
- Use muted gray for descriptions, secondary labels, and supporting information.
- Use subtle green backgrounds and green text for success states and availability indicators.
- Use muted gray backgrounds for disabled actions and unavailable statuses.
- Use thin, light-gray borders to separate components without making the interface look heavy.

Suggested starting colors:
- Primary blue: #2860E8
- Main text: #172033
- Secondary text: #758194
- Page background: #FFFFFF
- Panel background: #F8FAFC
- Border: #E2E7EE
- Success background: #EAFBF4
- Success text: #087B59

Treat these as starting values, not rigid requirements. Adjust them when needed to maintain consistency and readability.

### Typography
- Use a clean sans-serif typeface such as Inter or the closest existing project font.
- Page headings should be bold, approximately 26–32px on desktop.
- Section headings should be bold, approximately 19–22px.
- Body text should generally be 14–16px.
- Supporting descriptions should use approximately 14–16px with muted colors.
- Use bold text for important values and primary actions.
- Maintain consistent font weights, line heights, and text sizes across the application.

Avoid excessive font sizes, decorative fonts, unnecessary uppercase text, and inconsistent typography.

### Borders, corners, and shadows
- Use thin, subtle borders around cards, form panels, and filter containers.
- Use moderately rounded corners, approximately 10–14px for larger cards.
- Use approximately 6–9px for inputs and buttons.
- Apply very subtle shadows only where they help distinguish surfaces.
- Keep the design flat and clean rather than using heavy shadows, thick borders, or excessive visual effects.

### Spacing
- Use a consistent spacing system based on multiples of 4px or 8px.
- Maintain clear separation between the header, page heading, filters, content cards, and page footer.
- Give cards and panels sufficient internal padding.
- Keep labels close to their corresponding inputs.
- Maintain consistent gaps between related elements.
- Use whitespace to make the interface easy to scan.
